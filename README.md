# VinTracker Aventura

App educativa independiente de VinTracker, optimizada para celular y preparada como PWA/APK.

## Incluye
- 8 misiones interactivas.
- Sistema de puntos e insignias.
- Biblioteca educativa desbloqueable.
- Vinchuca guía animada.
- Progreso guardado en el dispositivo.
- Funcionamiento offline mediante service worker.
- Diseño responsive para Android, iPhone y escritorio.

## Publicar
Subí todos los archivos a un repositorio de GitHub y desplegalo en Vercel como sitio estático.
Luego puede empaquetarse como APK/AAB con PWABuilder.

## Nota sanitaria
VinTracker Aventura es una herramienta educativa. No diagnostica enfermedad de Chagas ni identifica de forma definitiva insectos.
